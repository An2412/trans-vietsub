Chưa kiểm tra server

Nhà cung cấp dịch thuật

Chưa tải trạng thái khóa. Bấm “Kiểm tra” để đọc cấu hình đã lưu.
Khóa chỉ được gửi tới server cục bộ và lưu trong kho bí mật của hệ điều hành. Không lưu vào Chrome, SQLite, mã nguồn hay log. “Kiểm tra API” gửi một câu mẫu và có thể dùng quota/chi phí API.
Gemini, OpenAI, Claude và Ollama có giao thức khác nhau; chỉ API key thuộc đúng provider mới dùng được. Nếu chưa cấu hình provider, server dùng dịch vụ miễn phí có thể bị giới hạn.

Tóm tắt bài học

Bấm “📋 Tóm tắt bài học” trong widget trên video để tạo ghi chú. Tắt “Ghi tiếp” nếu muốn mỗi video một tài liệu riêng.

Google Docs

Hướng dẫn tạo OAuth Client (làm 1 lần)
  1. Vào console.cloud.google.com → tạo project → bật API Google Docs API và Google Drive API.
  2. Menu APIs & Services → Credentials → Create credentials → OAuth client ID.
  3. Loại ứng dụng: Desktop app (bắt buộc, để dùng được redirect 127.0.0.1).
  4. Thêm Authorized redirect URI: http://127.0.0.1:8765/google-auth/callback.
  5. Dán Client ID + Client Secret vào ô trên, bấm “Lưu client”, rồi “Đăng nhập Google”.
  6. Lần đầu bấm “Đăng nhập Google” hãy chọn tài khoản và chấp nhận quyền truy cập Docs/Drive.

Notion

Hướng dẫn tạo Notion integration (làm 1 lần)
  1. Vào notion.so/my-integrations → New integration → đặt tên, chọn workspace.
  2. Copy Internal Integration Token (dạng secret_...) dán vào ô trên.
  3. Mở trang Notion muốn làm thư mục cha → … → Connections → Invite → chọn integration vừa tạo.
  4. Lấy page ID: mở trang đó bằng Notion API trên web, hoặc dùng notion.so/<page-id> ở cuối URL, rồi bỏ dấu gạch ngang.
  5. Bấm “Kiểm tra & lưu”. Mỗi video sẽ tạo một trang con trong trang cha đó.
