Chưa kiểm tra server

Nhà cung cấp dịch thuật

Chưa tải trạng thái khóa. Bấm “Kiểm tra” để đọc cấu hình đã lưu.
Khóa chỉ được gửi tới server cục bộ và lưu trong kho bí mật của hệ điều hành. Không lưu vào Chrome, SQLite, mã nguồn hay log. “Kiểm tra API” gửi một câu mẫu và có thể dùng quota/chi phí API.
Gemini, OpenAI, Claude và Ollama có giao thức khác nhau; chỉ API key thuộc đúng provider mới dùng được. Nếu chưa cấu hình provider, server dùng dịch vụ miễn phí có thể bị giới hạn.
